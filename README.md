## 📖 Overview

This repository contains the source code for my personal portfolio and product builder showcase. It is designed not just as a static resume, but as a deeply interactive, aesthetic web application that highlights real-world SaaS products, AI automation systems, and engineering capabilities.

The project leverages modern React patterns, utilizing **TanStack Start** for routing and SSR, **Framer Motion** for scroll-linked micro-interactions, and **Tailwind CSS v4** for utility-first styling.

---

## ⚡ Tech Stack

This project is built using the cutting-edge modern web ecosystem:

- **Framework**: [TanStack Start](https://tanstack.com/start/latest) (powered by [TanStack Router](https://tanstack.com/router/latest))
- **UI Library**: [React 19](https://react.dev/)
- **State Management**: [TanStack Query (React Query)](https://tanstack.com/query/latest)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **UI Primitives**: [Radix UI](https://www.radix-ui.com/) & Shadcn UI architecture
- **Form Handling**: [React Hook Form](https://react-hook-form.com/) + [Zod](https://zod.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)

---

## ✨ Key Features

- **High-Performance Routing**: File-based, type-safe routing powered by TanStack Router.
- **Scroll-Linked Animations**: Complex viewport-driven animations utilizing Framer Motion's `useScroll` and `useTransform`.
- **Premium UI/UX**: Includes custom cursors, magnetic buttons, typing rotators, and glassmorphic navigation.
- **SEO Optimized**: Native integration of JSON-LD structured data and comprehensive OpenGraph meta tags.
- **Modular Project Showcases**: Deep-dive modals and components explaining end-to-end system architectures (e.g., EduAuto OCR pipeline).

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18+ recommended) or [Bun](https://bun.sh/) installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/krishmunjal01/Krish_Munjal_Portfolio.git
   cd Krish_Munjal_Portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   # OR
   bun install
   ```

### Development

Start the development server:

```bash
npm run dev
# OR
bun run dev
```

The application will be available at `http://localhost:5173` (or the port specified by Vite).

### Building for Production

To create a production-ready build:

```bash
npm run build
# OR
bun run build
```
